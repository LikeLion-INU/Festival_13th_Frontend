# 너 나랑 통했네 🌸

멋쟁이사자처럼 인천대학교 13기 축제 프로젝트로, 키워드를 활용한 매칭 서비스입니다.

## 주요 기능

- **키워드 선택:** 질문과 키워드를 선택하는 화면
- **결과 확인:** 선택 결과를 보여주는 화면

## 기술 스택

- **Frontend:** React, JavaScript, Create React App
- **Styling:** styled-components
- **Routing:** React Router
- **API:** Axios

## 실행 방법

```bash
npm install
npm start
```

프로덕션 빌드:

```bash
npm run build
```

API를 사용하는 기능은 별도의 서버 연결이 필요합니다.
